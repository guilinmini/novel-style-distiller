# Long-form fiction knowledge router

- Library ID: `novel-longform-craft`
- Version: `1.0.0`

These modules provide project-internal craft guidance. They are not source-style evidence and do not replace the locked `WRITING_STYLE_CONTRACT.md`.

Load only the modules needed for the current task:

| Current problem | Load |
|---|---|
| Premise, ending, act/volume design, escalation | [story-architecture.md](story-architecture.md) |
| Character arc, motivation, relationship change, voice identity | [character-and-relationships.md](character-and-relationships.md) |
| World rules, systems, institutions, terminology, exposition | [worldbuilding-and-exposition.md](worldbuilding-and-exposition.md) |
| Chapter blueprint, scene turn, entry/exit, scene-sequel balance | [scene-and-chapter-design.md](scene-and-chapter-design.md) |
| Slow middle, rushed climax, tension, chapter rhythm | [pacing-and-tension.md](pacing-and-tension.md) |
| POV, knowledge boundaries, mystery, reveal/withhold decisions | [pov-and-information.md](pov-and-information.md) |
| Dialogue objectives, subtext, exposition, speaker differentiation | [dialogue-and-subtext.md](dialogue-and-subtext.md) |
| Foreshadowing, promises, open threads, payoff timing | [foreshadowing-and-payoff.md](foreshadowing-and-payoff.md) |
| Genre promise, serial cadence, recurring rewards, arc renewal | [genre-and-serialization.md](genre-and-serialization.md) |
| Contradictions, retroactive edits, continuity and revision impact | [continuity-and-revision.md](continuity-and-revision.md) |
| Applying the distilled contract without style drift or repetition | [style-integration.md](style-integration.md) |

Priority when guidance conflicts:

```text
explicit user requirement
→ accepted canon and hard world rules
→ character knowledge, POV, and timeline
→ current chapter contract
→ locked distilled style contract
→ general craft guidance in this directory
```

These files may suggest alternatives, but they must not silently change the user's theme, accepted facts, planned ending, or locked style version.
