# Chinese serial web-fiction knowledge router

- Library ID: `web-fiction-longform-craft`
- Version: `2.0.0`

These modules provide project-internal craft guidance for long-running Chinese web fiction with visible progression, recurring reader reward, and strong retention. They are not source-style evidence and do not replace the locked `WRITING_STYLE_CONTRACT.md`.

Load only the modules needed for the current task:

| Current problem | Load |
|---|---|

| Chapter entry/exit, hook variety, retention, overdue promises | [hooks-and-retention.md](hooks-and-retention.md) |
| 爽点, suppression/payoff debt, progression, escalation | [gratification-and-escalation.md](gratification-and-escalation.md) |
| Chapter-group emotion wave, recovery, emotional payoff | [emotion-curve-and-payoff.md](emotion-curve-and-payoff.md) |

## Default web-fiction set

- During project setup and opening planning, load `web-fiction-opening.md`, `gratification-and-escalation.md`, `genre-and-serialization.md`, and `story-architecture.md`.
- For every chapter blueprint, load `hooks-and-retention.md` and `gratification-and-escalation.md`; load `emotion-curve-and-payoff.md` when planning a chapter group or emotional turn.
- During every chapter review, apply `natural-prose-diagnostics.md` together with the locked style contract.
- During batch writing, use `SERIAL_RHYTHM.md` and `REWARD_LEDGER.md` to vary hook family, reward family/intensity, and reader-emotion movement across the rolling horizon.

Priority when guidance conflicts:

```text
explicit user requirement
→ accepted canon and hard world rules
→ character knowledge, POV, and timeline
→ current chapter contract
→ locked distilled style contract
→ general craft guidance in this directory
```

These files may suggest alternatives, but they must not silently change the user's theme, accepted facts, planned ending, or locked style version.
