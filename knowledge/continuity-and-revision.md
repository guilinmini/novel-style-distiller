# Continuity and revision

Use this module when diagnosing contradictions, revising accepted chapters, changing plans, or preparing continuity review.

## Sources of truth

Use this authority order:

1. explicit user decisions;
2. accepted chapter text and its chapter record;
3. canon timeline and entity state;
4. stable Story Bible rules;
5. outline and future plans;
6. unaccepted drafts and ideas.

The outline loses conflicts with accepted canon. Do not silently rewrite history to make the plan appear correct.

## Continuity dimensions

Check independently:

- chronology, duration, travel, season, age and deadlines;
- location and physical presence;
- injuries, abilities, inventory, money and other resources;
- character knowledge, secrets, lies and reader knowledge;
- relationships, promises, debts and authority;
- world rules, terminology and institutional constraints;
- unresolved threads and prior explicit commitments;
- POV, tense and naming consistency.

## Revision classification

Classify before editing:

| Class | Example | Required propagation |
|---|---|---|
| prose-only | rhythm, clarity, imagery without fact change | chapter text and style review |
| local canon | object owner, location, minor knowledge | chapter record and affected ledgers |
| causal canon | choice, reveal, relationship or outcome | all dependent later chapters and state |
| structural | ending, act turn, major arc, world rule | user confirmation plus outline and dependency rebuild |

## Impact analysis

For canon-changing revision, trace:

```text
changed fact/event
→ characters who know or act on it
→ relationships and objects affected
→ threads opened/closed
→ later scenes depending on it
→ current state and planned chapters
```

Record the analysis before mutation. Apply approved changes in chronological order, preserve superseded IDs or revision notes, and rerun continuity and style checks.

## Contradiction repair

Prefer the smallest repair that preserves accepted reader experience. Options:

- correct a mistaken state file when prose is unambiguous;
- add a missing acquisition or transition only if it does not feel retrofitted;
- reinterpret an ambiguous earlier fact;
- explicitly revise affected prose with user approval;
- change future outline rather than accepted history.

Never resolve a contradiction by inventing an untracked exception to a hard world rule.
