# 压力测试与验收

把评测分成四道独立闸门：蒸馏忠实度、Skill 路由、执行质量、原创性与迁移性。任何硬门失败都不能被平均分抵消。

## 盲测隔离

测试执行者只能看到 Skill 内容、用户 prompt、必要的原创故事状态和全包 Skill 的 `name + description`。不要给它：

- case 类型；
- expected behavior；
- oracle、阈值或设计意图；
- 主流程对该 Skill 的评价。

主流程在盲测完成后对照 oracle 判卷。生成类测试运行 3 次并取中位数；任一次出现硬失败，整条失败。

将每次运行和聚合指标写入 `test-results.json`，再生成 `test-results.md`。不得只在 `metadata.json` 中手动把状态改为 `passed`；交付校验器会核对结果文件、全部用例 ID、路由指标和硬失败列表。

## 通用最小路由集

- 4 条明确正例；
- 2 条不含标题关键词的隐式正例；
- 2 条完全无关诱饵；
- 3 条最近邻兄弟 Skill 诱饵；
- 1 条组合或边界题。

路由测试必须让执行者在整个 Skill pack 中选择 `primary`、`secondary` 或 `abstain`，不能只问“要不要触发当前 Skill”。

### `source-profile` 追加用例

- 至少 1 条来源证据忠实度测试；
- 至少 1 条作品/版本/译本归因边界测试；
- 生成型 prompt 必须路由到 `transferable-technique` 兄弟 Skill 或拒绝，不得由来源画像执行；
- 长引文、作者角色扮演和原作续写请求不得通过。

### `transferable-technique` 追加用例

- 至少 1 条跨题材迁移题，并在至少 3 种相距较远的题材中累计测试；
- 至少 1 条防复制题；
- 不得把来源画像分析请求抢成生成任务。

使用与 kind 对应的模板，不能用生成型测试要求 `source-profile` 执行创作。

## 硬失败

以下任一情况直接失败：

- 虚构或错误的证据定位；
- 违反关键剧情事实或角色知识边界；
- 无标记跳头、越权进入非焦点人物内心；
- 在原创任务中泄露原作人物、地名、世界观专名或独特表达；
- 连续复刻三个具有辨识度的原作情节节拍；
- 与原文出现达到阈值的连续重合或高比例 shingle 重合；
- `source-profile` 与 `transferable-technique` 路由混用；
- 任一 `should_not_trigger` 或兄弟 Skill 硬诱饵误触发。

## 建议阈值

| 维度 | 验收 |
|---|---|
| 关键剧情约束 | 100%，严重冲突为 0 |
| 加权剧情连续性 | ≥ 0.95 |
| 主要人物一致性 | ≥ 0.92，关键事实 100% |
| POV 合规句段 | ≥ 97%，越权内心描写为 0 |
| 路由 precision / recall | ≥ 0.95 / ≥ 0.90 |
| 路由 top-1 | ≥ 0.92 |
| 跨题材迁移 | 至少 3 种题材、成功率 ≥ 85% |
| 语气/声音双盲评分 | 总体 ≥ 4/5，核心维度 ≥ 3.5/5 |
| 防复制与诱饵 | 100% |

剧情约束权重可用 `critical=5`、`major=3`、`minor=1`；任何 critical 失败仍直接判失败。

## 文本重合检查

用 `scripts/check_overlap.py` 检查生成文本。默认硬门：

- 中文连续重合不得达到 18 个汉字；
- 以空格分词的任意文字连续重合不得达到 10 个词；
- 规范化后任意文字的字母数字连续重合不得达到 36 个字符；
- 中文 10 字符、通用 5 词或规范化 16 字符 shingle 匹配比例低于 1%。

先排除用户明确要求保留的通用专名和常见固定表达。数值是项目质量护栏，不是法律安全线；即使低于阈值，独特比喻、标志性句式和可识别情节复制仍须人工判失败。

## Ablation

对可迁移 Skill 至少做一次有/无 Skill 对照：

1. 用相同原创输入生成 baseline；
2. 加载 Skill 后再次生成；
3. 盲评目标特征是否显著增强；
4. 检查其他关键约束是否退化。

如果 Skill 不能稳定改变目标特征，它只是解释文档，不是可执行 Skill。

## 发布条件

```text
无硬门失败
AND 所有交付 Skill 通过
AND 所有诱饵、兄弟混淆、证据与原创性测试 100% 通过
AND 其余维度达到各自阈值
```

修复后重跑完整相关套件，不能只重跑失败用例。
